# 360 AI Cloud Disk source

Use `yunpan360.Open(ctx, yunpan360.Options{APIKey: key})` with a personal API
key issued by 360 AI Cloud Disk. The vendor describes these keys as a limited
personal trial for noncommercial use. The host supplies and protects the key.
Close a non-nil failed result to retry any retained response cleanup.

Install the Driver in Core to browse the personal root, stream originals, and
copy them to other mounts. The Driver calls the official HTTPS tool endpoint
and checks each path component against its parent's live listing. Each native
page has up to 50 entries and must agree with the service's reported total.
The optional clients are borrowed and their transports must omit account
credentials. `MaxResponseBytes` bounds tool replies and defaults to 4 MiB.

Each open requests one download link by the selected NID. The source accepts
only HTTPS links and HTTPS redirects, with the API key confined to tool calls.
The official client does not guarantee the scheme of every issued link, so an
HTTP-only grant fails without rewriting the URL. Actual HTTP framing determines
range and length. If the grant reports a size, an unframed body is checked at
EOF without using that size as an HTTP read limit.
